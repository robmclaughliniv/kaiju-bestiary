# Bestiary artwork

One image per catalog number is used on the dex grid and entry page. Art is
**optional** for contributions — the site generates a guild seal when no image
is present.

## File naming

```
art/images/NNN-anything.png
```

- `NNN` — three-digit catalog number (e.g. `112`)
- `anything` — descriptive slug (e.g. `cindermaw-hero`)
- Formats: `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`

Examples:

- `art/images/112-cindermaw-hero.png`
- `art/images/046-mirewalker.jpg`

The site matches by number prefix only; the rest of the filename is free.

## Display

Images appear on dex cards and entry headers. Roughly square aspect ratios
work best (~1:1). Keep file sizes reasonable for web delivery.
